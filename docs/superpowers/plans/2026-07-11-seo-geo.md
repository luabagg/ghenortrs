# SEO And GEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every public GHENO route accurate, crawlable metadata and structured context, publish complete crawl/LLM discovery files, and make direct route requests deploy safely.

**Architecture:** Keep one typed route-SEO registry as source of truth for client-side navigation and build output. A small React head synchronizer updates metadata after SPA navigation, while a Vite build plugin emits route-specific HTML entry points so crawlers and social unfurlers receive correct metadata without JavaScript. Static discovery files use the verified production origin `https://ghenortrs.vercel.app` and describe only facts already present in project sources.

**Tech Stack:** React 19, React Router 7, TypeScript, Vite 8, Vitest, Testing Library, JSON-LD, XML sitemap, robots.txt, llms.txt.

## Global Constraints

- Do not invent company facts, addresses, reviews, ratings, metrics, product availability, or unsupported claims.
- Preserve the external Nuvemshop checkout boundary and owned route definitions.
- Use absolute canonical, Open Graph, structured-data, sitemap, and LLM URLs.
- Unknown routes must be `noindex, nofollow` and excluded from sitemap.
- No new runtime SEO dependency for deterministic DOM updates.
